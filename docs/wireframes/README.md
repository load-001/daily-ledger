# 线框图说明（Step 0.3）

四张图，每张同时给出桌面 1440px 与手机 375px 两种布局。

| 文件 | 页面 | 桌面形态 | 手机形态 |
|---|---|---|---|
| 01-login.png | 登录 / 注册 | 居中卡片 | 满宽卡片 |
| 02-home.png | 首页 | 2 列 + 通栏流水 | 单列，流水在首屏外 |
| 03-expenses.png | 流水 | 表格 + 分页 | 卡片 + 加载更多 |
| 04-reports.png | 月报 | 3 统计卡 + 双图 | 单列，图表 150px |

## 每页的三个问题

### 01 登录
1. 唯一任务：登录。注册是同一页的第二个 tab，不单独开路由。
2. 第一眼：邮箱、密码、登录按钮、错误提示。
3. 手机端：卡片满宽，按钮仍不换行；错误提示贴在按钮上方，不用 toast。

### 02 首页
1. 唯一任务：记一笔。其他都是"记完之后看到的反馈"。
2. 第一眼：金额输入 + 今日总额。分类小计和最近流水是二等信息。
3. 手机端：5 个块放不下一屏，砍到 4 块，最近 5 笔移到首屏外（图中虚线即 375×667 首屏边界）。

### 03 流水
1. 唯一任务：找到某个月的那一笔并改/删。
2. 第一眼：当前月份、本月合计、列表金额列。
3. 手机端：表格在 375px 会挤成三行，改成卡片；编辑/删除收进右侧点点点。

### 04 月报
1. 唯一任务：回答"这个月花超了吗"。
2. 第一眼：总支出、预算进度、环比。图表是解释，不是结论。
3. 手机端：单列，图表压到 150px；预算设置移到首屏外（低频操作）。

## 已知取舍

- 首页在手机上必须舍弃一块，选择舍弃"最近 5 笔"，因为它有"查看全部"入口兜底。
- 预算卡在桌面放右侧固定位，在手机上跟随记一笔之后，因为"还能花多少"影响当下的消费决策。
- 图表只在月报出现，首页不画图，避免首屏变重。
