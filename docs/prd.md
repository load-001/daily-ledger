# Daily Ledger 产品需求文档（MVP）

- 版本：v0.1
- 日期：2026-11-18
- 作者：load-001
- 状态：Step 0 初稿

## 1. 背景与目标

Daily Ledger 是一个面向个人的每日记账 Web 应用，解决三个问题：

1. 今天花了多少、花在哪
2. 这个月还剩多少预算
3. 这个月整体花得怎么样

MVP 目标：让一个用户从注册到看懂本月消费，不超过 5 分钟。

成功标准：

- 新用户能在 3 分钟内完成注册、记第一笔、看到今日汇总
- 一个月的流水能在 3 次点击内找到
- 月报能回答：花了多少、花在哪、是否超预算
- 线上可访问，手机和电脑都能正常使用

## 2. 目标用户

- 刚工作、想控制月度开销的个人用户
- 单人使用，不做家庭共享、多账本
- 使用人民币，时区 Asia/Shanghai

## 3. MVP 范围

### P0 用户故事

| 编号 | 用户故事                                             | 验收要点                                                     |
| ---- | ---------------------------------------------------- | ------------------------------------------------------------ |
| US-1 | 作为用户，我能注册、登录、退出，且只能看到自己的数据 | 邮箱唯一；密码加密；未登录访问页面跳登录；A 不能读/改 B 的数据 |
| US-2 | 作为用户，我能记一笔支出                             | 金额、分类、日期、备注；金额 > 0；日期不能晚于今天           |
| US-3 | 作为用户，我能看到今天的总支出和分类去向             | 今日总额、笔数、分类小计、最近 5 笔                          |
| US-4 | 作为用户，我能按月查看流水，并编辑/删除              | 分页、按分类筛选、按日期倒序；删除为软删除                   |
| US-5 | 作为用户，我能设置每月预算                           | 每月一条；可修改；显示已花、剩余、百分比                     |
| US-6 | 作为用户，我能查看月度报告                           | 总支出、预算对比、分类占比、每日趋势、环比、最大支出日       |

### 非目标（MVP 不做）

- 多账本、家庭共享、多人协作
- 多币种、收入记账、转账、借贷
- 账单导入、OCR、周期账单
- 自定义分类、标签、附件
- 邮件/推送提醒、定时生成月报
- PDF/Excel 导出
- 后台管理、RBAC、审计日志
- 微服务、消息队列、Elasticsearch
- 原生 App、小程序

## 4. 核心流程

1. 注册 / 登录
2. 首页记一笔，立即看到今日汇总
3. 进入流水页，按月查看、修改、删除
4. 在月报页设置预算，查看本月报告
5. 退出登录

## 5. 功能需求

### 5.1 注册与登录

- 邮箱 + 密码注册；邮箱全局唯一
- 密码 8–32 个字符；BCrypt 加密存储
- 登录失败提示统一为“邮箱或密码错误”，不暴露账号是否存在
- 连续失败 5 次，锁定 15 分钟（按邮箱 + IP 计数，Redis）
- 登录后 Session 默认 30 分钟无操作过期
- 退出登录立即失效 Session
- 所有 `/api/**` 和业务页面都要求登录；登录、注册、静态资源除外

### 5.2 记一笔

字段：

- 金额：必填，最多两位小数，> 0，≤ 1,000,000.00
- 分类：必填，必须是系统预设分类之一
- 日期：必填，默认今天，不能晚于今天
- 备注：可选，最多 200 字

规则：

- 创建成功后，今日汇总和月报数据要同步变化
- 编辑后，旧日期/旧月份的汇总不能残留
- 删除为软删除，删除后不再出现在列表和统计中

### 5.3 今日汇总

- 今日总支出
- 今日笔数
- 按分类的小计和占比
- 最近 5 笔支出
- 没有数据时显示空状态，不显示 0 元图表

### 5.4 月度流水

- 月份选择器，默认当前月
- 列表按日期倒序、同一天按创建时间倒序
- 每页 20 条，支持上一页/下一页
- 可按分类筛选
- 支持编辑、删除；删除前二次确认
- 列表顶部显示本月合计（与月报一致）

### 5.5 月度预算

- 每个用户每个月最多一条预算
- 预算金额 ≥ 0，最多两位小数
- 不结转、不按分类设置
- 显示：预算、已花、剩余、使用百分比
- 剩余为负时显示“已超支”，不隐藏负数
- 未设置预算时显示“未设置预算”，不阻塞记账

### 5.6 月度报告

- 可选择当前月或历史月份
- 总支出
- 预算对比：预算、已花、剩余、百分比
- 分类占比：金额 + 百分比，合计 100%（四舍五入误差 ±0.1%）
- 每日趋势：按天汇总的柱状图/折线图
- 环比：与上个月总支出比较；上月无数据显示“—”
- 最大支出日：单日总支出最高的一天；并列取最早一天
- 总支出为 0 时显示空状态，不显示除零错误

### 5.7 分类

MVP 固定 8 个系统分类：

餐饮、交通、购物、居住、娱乐、医疗、学习、其他

不支持新增、改名、删除。

### 5.8 页面

| 页面 | 路径      | 内容                                 |
| ---- | --------- | ------------------------------------ |
| 登录 | /login    | 登录表单，可切换注册                 |
| 首页 | /         | 记一笔、今日汇总、最近流水、预算卡片 |
| 流水 | /expenses | 月份选择、筛选、分页、编辑/删除      |
| 月报 | /reports  | 预算设置、月度报告、图表             |

手机端（375px）要求：

- 单列布局，无横向滚动
- 底部或顶部导航可切换首页/流水/月报
- 记一笔表单在首屏可完成
- 图表高度不超过一屏

## 6. 数据规则

- 金额统一用 DECIMAL(12,2)，Java 用 BigDecimal
- 日期用 DATE；月份用 `yyyy-MM`，数据库存当月 1 日
- 时区固定 Asia/Shanghai
- 所有业务表带 user_id；所有查询必须带 user_id 条件
- 支出软删除：deleted_at 不为空即已删除
- 预算唯一键：(user_id, budget_month)
- 分类为系统数据，不随用户删除

## 7. 非功能需求

### 响应式

- 支持 375px、768px、1440px 三个宽度
- 手机端主要流程可完成，不依赖 hover

### 性能

- 本地 1 万条流水/用户时，列表和月报接口 P95 < 500ms
- 首页首屏本地加载 < 2s
- Render 免费实例冷启动可能 30–60 秒，页面显示加载状态，不视为 bug

### 安全

- 密码 BCrypt（strength 10）
- Session Cookie：HttpOnly、SameSite=Lax；生产 HTTPS 下 Secure
- 所有写请求开启 CSRF 校验
- 防 SQL 注入：MyBatis-Plus 参数绑定，不拼接 SQL
- 防 IDOR：按 id 查询/修改时必须同时校验 user_id
- 登录限流：5 次失败/15 分钟
- 生产环境不暴露 Swagger、堆栈、SQL 日志

### 兼容性

- 最新版 Chrome、Edge、Safari
- iOS Safari 16+、Android Chrome

### 可观测性

- `/actuator/health` 可用
- 错误日志包含请求路径和用户 id，不记录密码、Session、完整 token

## 8. 验收标准

MVP 完成需同时满足：

1. 注册、登录、退出可用；重复邮箱、错误密码有明确提示
2. 用户 A 无法读取、修改、删除用户 B 的任何数据
3. 记一笔后，今日汇总、月流水、月报数字一致
4. 金额、日期、备注的非法输入被拒绝，且不产生脏数据
5. 编辑跨月日期后，旧月份和新月份统计都正确
6. 删除后列表和统计都不再包含该笔
7. 预算设置/修改后，剩余和百分比正确；未设置预算不报错
8. 月报的分类占比、每日趋势、环比、最大支出日与数据库聚合结果一致
9. 375px 宽度下无横向滚动，记一笔和看月报可完成
10. `mvn verify` 通过，GitHub Actions 绿色
11. 线上地址可访问，手机可完成“注册→记一笔→看今日→看月报”

## 9. 风险与假设

- Render 免费实例会休眠，冷启动慢；演示前先预热
- TiDB Cloud Serverless 和 Redis Cloud 免费额度有限，不能压测
- 无域名，使用平台分配的 HTTPS 地址
- 单人使用，暂不考虑并发写同一用户的极端场景
- 不做数据迁移/多端同步，先保证单端可用

## 10. 已决策问题

- 分类：MVP 固定，不做自定义
- 月报：随时可看，不做定时任务
- 预算：每月一条，不结转、不分分类
- 收入：MVP 不记收入，只记支出
- 未来日期：不允许
- 删除：软删除，不提供恢复入口
